# Ballchemy 전체 밸런스 기준

작성일: 2026-09-02

## 목표

- 한 런은 6개 스테이지와 6번의 보스전을 사용한다.
- 플레이어는 기본 1성 공 20개로 시작한다.
- 공 개수는 모든 빌드의 공통 성장축이다.
- 일반적인 완주 시 130~170개, 공 보상을 적극적으로 선택하면 200개 이상을 목표로 한다.
- 폐기된 1차/2차 계열과 정제 빌드는 사용하지 않는다. 등급 관련 개별 보상과 증강은 독립 선택지로만 유지한다.

## 공 성장 목표

| 시점 | 목표 공 개수 | 주된 획득처 |
|---|---:|---|
| 런 시작 | 20 | 기본 1성 공 |
| 1보스 진입 | 30~40 | Tier 1 공 보상 |
| 2보스 진입 | 45~60 | Tier 1/2 공 보상, 이벤트 |
| 3보스 진입 | 65~85 | 속성 공 보상, 특수 블럭 |
| 4보스 진입 | 90~115 | Tier 2 공 보상 |
| 5보스 진입 | 115~145 | 이벤트와 공 보상 누적 |
| 최종 보스 | 130~170 | 일반 경로 목표 |
| 공 집중 경로 | 200+ | 공 보상 우선 선택과 긍정 이벤트 |

공 보상 기준은 Tier 1 기본 공 5개, Tier 1 속성 공 3개, Tier 2 기본 공 10개,
Tier 2 1성 속성 공 6개, Tier 2 2성 속성 공 3개다. 긍정 이벤트의 대량 공 보상은 15개와 25개다.

## 피해 기준

- 공통 기본 직접 피해는 2다.
- 기본 공 직접 피해는 1성 2, 2성 3, 3성 5다.
- 체력 설계는 모든 공이 한 번씩만 충돌하는 이론 피해가 아니라 실제 반사, 속성 반응, 증강을 포함한 턴 피해로 검증한다.
- 일반 전투는 평균 3~5턴, 보스전은 평균 6~9턴을 목표로 한다.

## 일반 적 체력

일반 전투의 기준 체력은 공 개수와 직접 피해가 함께 증가하는 것을 반영해 가속 곡선을 사용한다.

`14 + 8 × 인덱스 + 4 × 인덱스 × max(인덱스 - 1, 0)`

| 스테이지 | 일반 블럭 기준 체력 |
|---|---:|
| 1 | 14 |
| 2 | 22 |
| 3 | 38 |
| 4 | 62 |
| 5 | 94 |
| 6 | 134 |

실제 체력은 역할 배율과 ±15% 변동을 적용한다. 공격형은 기준의 55%, 탱커는 200%, 엘리트는 150%,
가디언은 특수 블럭 체력의 120%를 사용한다.

## 보스 체력

보스는 등장 순서가 무작위이므로 보스 에셋 이름이나 제작 번호로 난이도를 결정하지 않는다.
각 보스 패턴의 기본 핵심 체력은 420~450으로 정규화하고, 실제 보스 핵심 체력은 다음 식을 사용한다.

`실제 보스 체력 = 기본 핵심 체력 × 1.55^(현재 스테이지 - 1)`

기본 체력 450 기준 목표는 다음과 같다.

| 스테이지 | 보스 핵심 체력 |
|---|---:|
| 1 | 450 |
| 2 | 698 |
| 3 | 1,081 |
| 4 | 1,676 |
| 5 | 2,598 |
| 6 | 4,027 |

## 직접 피해 성장 반영

- 영구 이벤트는 모든 공의 직접 피해를 +1, +2 또는 +3 증가시킬 수 있다.
- 응축 화력 증강은 레벨에 따라 누적 +1/+2/+3 직접 피해를 제공한다.
- 상점 공격 촉매는 해당 스테이지 직접 피해를 20% 증가시킨다.
- 기본 1성 공은 직접 피해 2이므로 +1도 50% 성장이다. 공 개수 증가와 곱해져 후반 화력이 크게 뛴다.
- 일반 적은 가속 곡선, 보스는 1.55배 복리 곡선을 사용해 이 곱연산 성장을 따라간다.
- 직접 피해 보상을 얻지 못한 런도 막히지 않아야 하므로 최대 화력에 맞춰 체력을 고정하지 않고,
  일반 성장 경로와 고화력 경로의 소요 턴 차이를 허용한다.

### 성장 편차 시뮬레이션 기준

보상과 증강이 특정 빌드에 맞지 않거나 성장 방을 적게 방문한 저성장 런, 일반적인 평균 런,
공·피해·속성 증강을 적극적으로 확보한 고성장 런을 각각 10회씩 비교한다.

| 구간 | 1스테이지 | 2스테이지 | 3스테이지 | 4스테이지 | 5스테이지 | 6스테이지 |
|---|---:|---:|---:|---:|---:|---:|
| 저성장 예상 보스 턴 | 8.8 | 8.2 | 8.9 | 9.2 | 10.2 | 11.4 |
| 평균 성장 예상 보스 턴 | 7.0 | 6.1 | 5.6 | 5.4 | 5.3 | 5.7 |
| 고성장 예상 보스 턴 | 6.4 | 4.7 | 3.9 | 3.3 | 3.6 | 3.7 |

저성장 런의 후반 보스는 평균보다 오래 걸리지만 진행 불가능한 체력 벽이 되지 않는 것을 목표로 한다.
반대로 고성장 런은 빠른 처치 자체가 보상 선택을 잘 연결한 결과로 체감되도록 허용한다.

## 속성 피해 성장

범용 직접 피해만 정답이 되지 않도록 핵심 속성 피해 증강의 선택 가중치를 1에서 2로 높인다.

- 화염 `잔불`: 화상 블럭 대상 피해 +15/+30/+45%
- 물 `응집수`: 젖은 블럭 대상 피해 +15/+30/+45%
- 물 `수압`: 최대 젖음 블럭 재타격 시 직접 피해의 50/100% 추가
- 번개 `전류 증폭`: 번개 추가 피해와 전도 피해 +15/+30/+45%
- 얼음 `취성`: 동결 블럭 대상 피해 +15/+30/+45%
- 독 `신경독`: 독 3스택 이상 블럭에 고정 피해 +5/+10/+15

속성 보상은 범용 직접 피해보다 조건이 있지만 광역 전파, 상태 누적, 반응 피해가 함께 발생한다.
따라서 단일 대상에서 항상 우위인 보상이 아니라 조건을 완성했을 때 총 피해가 더 커지는 선택지로 유지한다.

여러 원소를 함께 사용하는 빌드에는 Value 1 `프리즘 증폭`을 제공한다.

- 불·물·번개·얼음 공의 직접 피해와 특성 추가 피해 +5/+10/+15%
- 특정 상태를 요구하지 않아 여러 원소의 비율을 자유롭게 구성할 수 있다.
- 기본 공과 독 공에는 적용되지 않아 범용 직접 피해 보상의 완전한 상위호환이 되지 않는다.
- 선택 가중치는 2로 두어 혼합 빌드의 초반 기반 증강으로 비교적 자주 제시한다.

보스별 소환물, 함정, 재생 블럭과 기믹 피해는 별도 체력 예산이다. 보스 핵심 체력만으로 총 전투 내구도를 비교하지 않는다.

## 발사 템포

- 기본 발사 간격은 0.03초다. 100개 발사에 약 3초, 200개 발사에 약 6초가 걸린다.
- 남은 공이 60% 이하가 되면 1.75배, 3초 뒤 2.5배 자동 가속한다.
- 남은 공이 15% 이하가 된 뒤 8초가 지나면 자동 회수한다.
- 공이 200개를 크게 넘는 빌드가 반복해서 등장하면 다음 단계로 묶음 발사와 물리/VFX 풀 상한을 프로파일링한다.

## 플레이어 생존 곡선

- 시작 최대 체력은 40이다.
- 일반 적은 3턴마다 공격하며 공격 가능한 엘리트의 기준 공격력은 2다.
- 보스 단일 직격 피해는 4, 선택 블럭 공격은 블럭당 2다.
- 보스를 처치하고 다음 스테이지로 진입하면 최대 체력의 20%(올림)를 즉시 회복한다.
- 이벤트방 즉시 회복은 최대 체력의 30%, 상점 회복은 최대 체력의 25%다.
- 최대 체력 증가 보상은 +5이며 현재 체력을 함께 채우지는 않는다.
- 저성장 런은 회복 경로를 무시하면 패배할 수 있지만, 평균 성장 런은 이벤트와 상점을 적절히 이용하면
  최종 보스까지 도달할 수 있는 것을 기준으로 한다.
- 생존 계산은 전투 턴 수, 실제 적 공격 횟수, 동결로 취소한 공격, 보스 기믹 피해와 회복 지출을 함께 기록한다.

시작 체력을 높여 실수를 일괄 흡수하는 방식 대신, 각 보스 구간을 넘긴 성과로 회복을 지급한다.
일반 전투방 클리어에는 기본 회복을 붙이지 않아, 방을 많이 도는 경로가 무조건 생존에도 유리해지지 않게 한다.
이벤트·상점 회복은 손실을 메우는 능동적 선택으로 남기고, 스테이지 회복은 다음 구간의 최저 생존력을 보장하는 안전망으로 사용한다.
실제 플레이 로그에서 평균 클리어율이 지나치게 높으면 시작 체력보다 스테이지 회복률을 15%로 먼저 낮춘다.

## 스테이지 계약 미션

- 각 스테이지 시작 시 서로 다른 카테고리의 미션 3개를 제시하고 1개를 선택한다.
- 선택지는 쉬움·보통·어려움이 하나씩 섞이며, 골드 단일 보상의 기준은 각각 25G·45G·70G다.
- 보스 처치 직후 성공을 판정하며 실패 페널티는 없다.
- 기본 8종은 피격 횟수, 누적 피해, 종료 체력, 공 증가량, 공 특성 종류, 전투방 클리어, 특수방 방문, 보스 턴 제한이다.
- 확장 풀은 서로 다른 방 방문, 스테이지 골드 획득·소비, 보스전 피격 제한, 후퇴 횟수 제한, 상점 구매, 보스 처치 시 골드 보유를 추가해 총 15종이다.
- 상점이 없는 맵에서는 골드 소비 미션을 제외하고, 방 수 조건은 실제 생성된 맵의 상한을 넘지 않도록 자동 보정한다.
- 피격 횟수·누적 피해·종료 체력은 같은 생존 카테고리로 묶어 동시 제시를 막는다.
- 보상 풀은 골드, 기본 공, 속성 공, 2성 공, 체력 회복, 최대 체력, 다음 일반 보상 승급, 증강, 무작위 공 승급, 기본 공 속성 변환, 상점 할인, 전투 골드 증가, 전체 직접 피해 증가 13종이다.
- 기본 공·속성 공·2성 공·증강은 기존 RewardCatalog의 유효성 규칙을 그대로 사용한다.
- 무작위 공 승급은 고정 3개가 아니라 승급 가능한 보유 공의 보통 10%·어려움 15%를 승급한다(올림, 최소 1개).
- 기본 공 속성 변환은 고정 3개가 아니라 1성 기본 공의 보통 15%·어려움 20%를 속성 공으로 변환한다(올림, 최소 1개).
- 회복·최대 체력·보상 승급·상급 공·증강에는 난이도에 따라 소량의 골드가 함께 붙을 수 있다.
- 런당 희귀 보상 상한은 2성 공 3회, 다음 보상 승급 2회, 증강 2회다.
- 증강형 미션 보상은 보스 기본 증강 선택지를 무효화하지 않도록 기존 보상 UI가 닫힌 뒤 지급한다.
- 목표 성공률은 쉬움 90%, 보통 70%, 어려움 50%다. 가중치·수량·성공률은 전체 밸런싱 단계에서 함께 조정한다.

## 공 등급 고유 효과

등급은 단순 수량이나 스택 배수만 올리는 대신 전투 역할을 바꾼다.

- 1성은 공 개수와 기본 상태 공급을 담당한다.
- 2성 물·화염·얼음·독은 인접 대상 한 곳으로 상태를 전개하고, 번개는 전도 대상을 하나 늘린다.
- 3성 물은 최대 젖음 완성 시 인접 전체로 젖음을 전파한다.
- 3성 화염은 최대 화상 완성 시 인접 전체에 화상과 직접 피해 50%를 전달한다.
- 3성 얼음은 동결 완성 시 인접 전체에 냉기와 직접 피해 50%를 전달한다.
- 3성 번개는 전도 대상을 둘 늘리고 마지막 대상에 직접 피해 50%를 추가한다.
- 3성 독은 최대 중첩 완성 시 두 대상에 전염하며 독 붕괴 피해를 25% 높인다.
- 2성 기본 공은 처치 시 인접 한 대상에게 피해 1, 3성은 인접 전체에 직접 피해 50%를 전달한다.
- 2성은 단일 외곽 링, 3성은 이중 링·밝은 코어·맥동으로 구분하고 고유 효과 발동 시 링이 짧게 확장된다.

## 경제와 흐름

- 시작 골드는 디버그 값 1,000에서 60으로 낮춘다.
- 일반 적 필수 블럭은 현재 4골드, 골드 특수 블럭은 10골드를 지급한다.
- 상점 가격은 20~70골드이므로 시작 시 저가 상품 1회 구매가 가능하고, 이후 구매는 전투 수입이 필요하다.
- 스테이지 맵은 9개 방에서 시작해 스테이지마다 2개씩 증가하며 최대 30개 방을 허용한다.
- 실제 도달 공 개수는 경로 선택과 공 보상 선택 비율에 따라 달라져야 한다.

## 플레이 테스트 판정

다음 값은 최소한 스테이지별로 기록한다.

- 보스 진입 시 공 개수와 등급/속성 분포
- 일반 전투와 보스전의 소요 턴
- 한 턴의 직접 피해, 간접 피해, 원소 피해
- 남은 적 체력과 플레이어가 받은 피해
- 획득 골드, 구매 횟수, 선택한 공 보상 수
- 발사부터 마지막 공 회수까지 걸린 시간과 최저 프레임

목표 범위를 두 번 이상 연속으로 벗어나면 개별 보스부터 조정하지 않고 공 성장량, 일반 체력 곡선,
보스 스테이지 배율 순으로 원인을 확인한다.
