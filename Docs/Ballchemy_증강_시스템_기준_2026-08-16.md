# Ballchemy 증강 시스템 기준

작성일: 2026-08-16

이 문서는 런 성장과 증강 보상의 최신 기준이다. 과거 문서의 1차/2차 계열, 전직, 특정 계열 고정, Stage 1/4 전직 선택 기획은 모두 폐기한다.

## 성장의 두 축

- 공 성장: 공 수량·등급·속성·구성을 획득하고 Alchemy에서 변환·정리한다. 즉 “무엇을 발사하는가”를 결정한다.
- 증강 성장: 보유 공의 작동 방식, 원소 반응, 전투 규칙을 바꾸는 런 단위 패시브다. 즉 “공이 어떻게 작동하는가”를 결정한다.

Normal/Named Combat의 기존 공 보상은 유지한다. Alchemy는 공 자체를 편집하며 증강을 지급하지 않는다. Shop도 이번 단계에서는 증강 핵심 공급처가 아니다.

## Value Tier

내부 데이터는 `AugmentValueTier.Value1/Value2/Value3`를 사용한다. 이는 희귀도나 순수 화력 순서가 아니라 플레이 규칙에 미치는 영향력의 크기다.

- Value 1: 작은 강화와 기존 효과의 수치 보강. 여러 개 조합해도 안전한 빌드 기초다.
- Value 2: 효과와 효과를 연결하고 원소·상태·반사 등의 시너지를 만든다.
- Value 3: 전투 규칙이나 플레이 방식을 크게 바꾸는 핵심 증강이다. 과거 전직이 맡으려던 역할을 대체한다.

상위 Value가 하위 Value의 단순 수치 상위호환이어서는 안 된다. 현재 빌드와 잘 맞는 Value 1/2가 맞지 않는 Value 3보다 좋은 선택일 수 있어야 한다. UI 용어와 최종 색상은 미정이며 데이터 Tier를 기반으로 추후 카드 외형을 구분한다.

## 공통 지급 및 초기 가중치

모든 지급처는 같은 증강 풀과 `RoomRewardGenerator.GenerateAugmentChoices`를 재사용한다. 각 후보 카드는 지급처의 Value 가중치를 독립적으로 추첨한 뒤 해당 Value의 적용 가능한 증강을 가중 선택한다.

| 지급처 | Value 1 | Value 2 | Value 3 |
|---|---:|---:|---:|
| Boss | 30 | 50 | 20 |
| Secret | 20 | 50 | 30 |
| Augment Room | 45 | 40 | 15 |

이는 확정 밸런스가 아니며 `AugmentRewardSettings` ScriptableObject에서 수정한다. Boss와 Secret은 현재 공통 API에 연결되어 있다. Augment Room은 증강의 정규 공급처이며 Stage 1부터 생성할 수 있다.

## 방별 역할

- Normal/Named: 기존 공 보상을 유지한다.
- Alchemy: 실제 공 위치 기반 선택, 속성 변환, 등급 성장, 안정도, 실패 위험, 공 정리를 유지하며 증강과 결합하지 않는다.
- Event: 현재 체력·최대 체력·공 추가/제거/변환·능력치·다음 보상 변경 등 기존 이벤트 보상 풀을 유지하며 정규 증강을 지급하지 않는다.
- Boss: 전직 대신 Boss 가중치의 증강 후보를 제공한다. 항상 Value 3가 나오지는 않는다.
- Secret: 기존 입장·Max HP 비용 구조를 유지하고 Secret 가중치의 증강 후보를 제공한다.
- Shop: 기존 상품 구조를 유지한다.

## Augment Room 확장 기준

`RoomType.Augment`와 `AugmentRewardSource.AugmentRoom`을 확장 지점으로 둔다. 후보 3개는 각각 독립적으로 Tier를 추첨할 수 있다. 설정의 최소 Stage는 1이다.

- Stage 1부터 생성 가능하다.
- 초기에는 모든 Stage가 동일한 `45/40/15` Value 가중치를 사용한다.
- 필요하면 플레이 테스트 후 Stage 구간별 가중치나 생성 확률을 별도 데이터로 확장한다.

이번 단계에서는 맵 생성 확률, 방 UI, 최종 색상·이펙트, 증강 콘텐츠 전체, 최종 수치 밸런스를 구현하지 않는다.

## 구현 책임 분리

- `AugmentDefinition`: 정적 데이터, Value Tier, 레벨별 효과 진입점
- `RunAugmentState`: 런 중 보유 증강과 레벨
- `AugmentRewardDefinition`: 획득 가능 여부와 적용
- `AugmentRewardSettings`: 지급처별 Value 가중치와 최소 Stage
- `RoomRewardGenerator`: 공 보상 생성과 별개인 공통 증강 후보 추첨
- 각 방 Controller: 지급처 종류와 선택 UI 흐름

새 증강은 공통 선택 로직이나 방 Controller 수정 없이 Definition·Reward 에셋을 카탈로그에 등록하는 구조를 유지한다.

## 현재 증강 풀

### Value 1

- 응축 화력: 모든 공의 직접 피해 누적 증가
- 운동 에너지: 반사 5/3/2회마다 직접 피해 +1, 비행당 최대 +3/+4/+5
- 선제 연금: 방 입장 시 적 체력 감소
- 맹독 농축: 독 최대 스택 +2/+4/+6
- 전도성 수막: 번개 전이 최대 대상 +1/+2/+3

### Value 2

- 과잉 전도: 젖은 블록으로 이어지는 감전 전도망의 추가 대상 +1/+2/+3
- 독성 전염: 최대 독 스택 블록 재타격 시 주변 1/2/3개 블록에 독 1/2/3스택 전파

### Value 3

- 분산 발사: 보유 공을 여러 방향으로 나누어 동시 발사
- 불안정한 진화: 확률적으로 해당 비행 동안 공 등급 상승
- 독성 붕괴: 최대 독 스택 블록 재타격 시 독을 소비하고 주변에 폭발 피해
